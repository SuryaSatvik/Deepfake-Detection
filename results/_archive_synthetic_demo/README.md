# Archived — synthetic demo outputs, NOT Celeb-DF-v2

These figures and the ablation CSV come from the earlier FSV-Net demo run on
**120 controlled synthetic clips**, before Celeb-DF-v2 was available. The fakes
in that run were built with exactly the defect TSC looks for, so TSC scored
AUC 1.000 on them.

**Do not quote any number from this folder as a result about real deepfakes.**
It is a sanity check that the machinery works, nothing more. The real numbers
live in `results/` and `docs/FINDINGS.md`.
